Need of Framework:
All common reusable code are already done by some developers in the world are called "Framework".
If user wants to talk to our application business logic then user not able to call our logic directly so that to call our logic we need to do some part of code to connect user request to business logic.
The connecting user request to calling business logic of application that code is done by some developers are called "Framework".

* For building any real-time application we need framework
* The common reusable code is done by developer and available in one central place.
* We need this code, so we take this code in the form of Jar file and add to our project. As a developer we only focus on application functionality.
* Easy to code, faster application dev, more enhanced features, no need boiler plate code.
