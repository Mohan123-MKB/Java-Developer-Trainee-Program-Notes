in application.properties, activate one profile which you want
when spring application comes up, it reads application.properties by default, and further checks the profile to be activated.
spring boot will read the application-<profile-name>.properties file and read the configuration from that file.
In our controller we use @Value and @PostConstruct annotations to read this property and print.
By changing the profile in application.properties we are able to see different profile-specific values are being printed in controller.

we can define configuration directly in application.properties.
something which is common for all environments, can be defined directly in application.properties
If the keys of application.properties are also defined in profile specific files, the profile values will override the application.properties value.
